# 🎮 Gamer Profile Generator

A beginner-friendly Python project that generates a formatted RPG-style gamer profile in the terminal.

## 📌 About the Project

This is my fourth Python project, created as part of my programming journey. It displays a fictional game character's profile, including their name, role, level, experience, and virtual money.

## ✨ Features

- Displays a fictional player's name and character class.
- Shows the character's level and experience.
- Displays virtual money.
- Uses formatted text and decorative borders.
- Organizes information using Python variables and f-strings.

## 🛠️ Built With

- **Python 3**

## 🚀 How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   ```bash
   python "main.py"
   ```

## 📚 What I Learned

- Working with variables and strings
- Using f-strings to format output
- Displaying information with `print()`
- Repeating strings to create decorative borders
- Organizing terminal output for readability
